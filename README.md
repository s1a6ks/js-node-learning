# JS/TS/Node.js Learning Workspace

Це навчальний репозиторій для переходу до backend-розробки на `JavaScript`, `TypeScript` і `Node.js`.

## Для чого цей репозиторій

Мета: спокійно відновити базу програмування там, де вона підзабулась, пройти потрібний для backend рівень `JavaScript`, потім перейти до `TypeScript`, `Node.js` і підготовки реального спільного проєкту з frontend-розробником.

Ми не вчимо весь `JavaScript` підряд. Ми беремо теми, які потрібні для:

- розуміння runtime-поведінки `JavaScript`
- впевненого переходу в `TypeScript`
- написання backend API на `Node.js`
- майбутньої командної роботи через GitHub

## Як ми працюємо

Основний формат:

1. Codex веде тему в правильному порядку.
2. Пояснення спочатку йде простими словами.
3. Порівняння з `C#` використовується тільки як допоміжний інструмент.
4. Якщо щось із бази програмування підзабулось, ми коротко освіжаємо це без поспіху.
5. Практика додається там, де тема справді потребує закріплення.
6. Прогрес фіксується в markdown-файлах.

## Поточний статус

Ми почали з `JavaScript`.

Пройдено:

- `Session 1`: `use strict`, `let`, `const`, `var`, базові типи, mutable object inside `const`

Наступна тема:

- `Session 2`: `null`, `undefined`, type conversion, truthy/falsy, `==` vs `===`
