# JS/TS/Node.js Learning Workspace

Це навчальний репозиторій для переходу з `C#` backend development до `JavaScript`, `TypeScript` і `Node.js`.

## Для чого цей репозиторій

Мета: пройти `JavaScript` на практичному рівні, потрібному для backend-розробки, потім перейти до `TypeScript`, `Node.js` і підготовки реального спільного проєкту з frontend-розробником.

Це не курс "JavaScript з нуля до всього на світі". Ми вчимо саме те, що потрібно для:

- розуміння runtime-поведінки `JavaScript`
- впевненого переходу в `TypeScript`
- написання backend API на `Node.js`
- майбутньої командної роботи через GitHub

## Як ми працюємо

Основний формат:

1. Codex веде тему в правильному порядку.
2. Пояснення йде через порівняння з `C#`.
3. Практика додається там, де `JavaScript` реально відрізняється.
4. Очевидні теми проходимо швидше.
5. Прогрес фіксуємо в markdown-файлах.

## Поточний статус

Ми почали з `JavaScript`.

Пройдена тема:

- `Session 1`: `use strict`, `let`, `const`, `var`, базові типи, mutable object inside `const`

Наступна тема:

- `Session 2`: `null`, `undefined`, type conversion, truthy/falsy, `==` vs `===`
