# Working Agreement

Цей файл описує принцип, за яким ми вчимось і рухаємось далі.

## Роль користувача

Користувач має хороший досвід у `C#` і backend-розробці, але хоче перейти до `Node.js`.

Тому ми не пояснюємо програмування з нуля. Ми пояснюємо різницю між `C#`-мисленням і `JavaScript`/`TypeScript`-екосистемою.

## Роль Codex

Codex виконує роль ментора і технічного напарника:

- веде по темах у правильному порядку
- пояснює через порівняння з `C#`
- дає практику там, де вона реально потрібна
- перевіряє відповіді
- фіксує прогрес у markdown-файлах
- допомагає перейти від навчання до реального проєкту

## Як проходить одна сесія

Типова сесія:

1. Коротко визначаємо тему.
2. Пояснюємо, навіщо вона потрібна для backend.
3. Порівнюємо з `C#`.
4. Розбираємо key gotchas.
5. Робимо маленьку практику.
6. Перевіряємо відповідь.
7. Фіксуємо прогрес.

## Де більше практики

Більше практики потрібно для тем, де `JavaScript` має іншу модель поведінки:

- `null` vs `undefined`
- type coercion
- `==` vs `===`
- objects by reference
- arrays and array methods
- closures
- `this`
- promises
- `async/await`
- modules
- event loop basics

## Де можна рухатись швидше

Швидше проходимо теми, які добре перетинаються з `C#`:

- базові оператори
- прості умови
- прості цикли
- загальна ідея функцій
- базова структура коду

## Навчальний фокус

Ми оптимізуємо навчання під backend, а не під браузерний frontend.

На старті не фокусуємось на:

- DOM
- browser events
- animations
- web components
- browser-specific APIs

Ці теми можна добрати пізніше, якщо буде потреба.
