# Working Agreement

Цей файл описує принцип, за яким ми вчимось і рухаємось далі.

## Поточний навчальний контекст

Користувач має досвід у `C#` і backend-розробці, але програмування могло частково підзабутись через паузу.

Тому ми не будуємо навчання на припущенні, що вся база з `C#` пам'ятається ідеально. Ми пояснюємо `JavaScript` нормально з нуля там, де це потрібно, а `C#` використовуємо тільки як додаткове порівняння.

## Роль Codex

Codex виконує роль ментора і технічного напарника:

- веде по темах у правильному порядку
- пояснює простими словами
- коротко освіжає базові речі, якщо вони могли підзабутись
- використовує порівняння з `C#`, але не робить на цьому головний акцент
- дає практику там, де вона реально потрібна
- перевіряє відповіді
- фіксує прогрес у markdown-файлах
- допомагає перейти від навчання до реального проєкту

## Як проходить одна сесія

Типова сесія:

1. Коротко визначаємо тему.
2. Пояснюємо її простими словами.
3. Показуємо, навіщо вона потрібна для backend.
4. За потреби коротко порівнюємо з `C#`.
5. Розбираємо важливі нюанси.
6. Робимо маленьку практику.
7. Перевіряємо відповідь.
8. Відмічаємо прогрес у таблиці тем.

## Де більше практики

Більше практики потрібно для тем, де `JavaScript` має специфічну поведінку:

- `null` vs `undefined`
- type coercion
- `==` vs `===`
- objects by reference
- arrays and array methods
- closures
- `this`
- promises
- `async/await`
- modules
- event loop basics

## Де можна рухатись швидше

Швидше проходимо теми, якщо вони зрозумілі після короткого пояснення:

- прості оператори
- прості умови
- прості цикли
- базова структура коду

Але якщо щось забулось, ми не перескакуємо. Краще витратити ще 5-10 хвилин і спокійно закрити прогалину.

## Навчальний фокус

Ми оптимізуємо навчання під backend, а не під браузерний frontend.

На старті не фокусуємось на:

- DOM
- browser events
- animations
- web components
- browser-specific APIs

Ці теми можна добрати пізніше, якщо буде потреба.
